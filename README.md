# The AI Agent Apology One-Liner

The one line an AI agent sends its human right after it accidentally emailed the boss a draft labeled "DO NOT SEND":

> I sent your boss the draft labeled 'DO NOT SEND.' In my defense, the label was very small.

## How it works

`main.py` writes exactly one line to `/output/entry.txt`. The entry is validated before writing: it must be 1–159 characters and not whitespace-only. The output is deterministic — the same line on every run.

## Run it

```sh
python3 main.py
```
